## 一、第 1 波 · 动效地基（**必须先做**，后面所有东西都挂在它上面）

### A1【P0】新建 `pet_motion.py`：**动效令牌表**（单一来源）
- 把散落各处的时长/缓动/幅度**收成一张表**（例如 `DUR.FEEDBACK=100ms` / `DUR.TRANSITION=200ms` / `DUR.LARGE=300ms` / `SCALE.PRESS=0.97` / `EASE.*`），**并注明每条的 HCI 依据**（局部反馈 ≤100ms · 状态转换 150–250ms · 大位移 300ms）。
- **⚠ 沿用的既有时长常量必须显式搬家进来**（不许两处并存）：先 grep 出全仓硬编码的时长/幅度，逐个搬 + 在原处留一句指路注释。
- **`pet_motion.py` 必须是纯常量 + 纯函数模块**（不 import Qt 之外的重物、不产生副作用）。

### A2【P0】「**减少动效**」开关（无障碍 + 尊重系统设置）
- 配置项 + 菜单开关；**开启后所有动效退化为"瞬时"或"最短时长"**（不是"少一点"，是**可预期地关掉**）。
- **默认值**：读系统设置（若可读）；读不到就默认**开启动效**（不擅自替用户降级）。
- **验收**：开关打开 → 逐条断言"该动的都不动了"；**每条动效都要能被这条开关覆盖**（用例逐条列举）。

### A3【P0】键盘可达 + 高对比度（与 UX F1 合并，**只做一次**）
- 键盘：Tab 顺序合理、Enter/Space 触发主按钮、Esc 关窗（**不许抢全局 Esc**）。
- 高对比度：跟随系统主题或配置；**对比度 ≥ 4.5:1**（用可计算的方式验，不靠眼看）。

## 二、第 1 波 · 视觉三件套（**悬停只做光晕 · 按下只补描边 · 点击涟漪**）

### A4【P0】悬停 = **只做光晕**（不缩放）· 按下 = **只补描边** · 点击 = **涟漪**
- **为什么这样切**：上一轮复盘出"按原则改坏"的教训——**悬停缩放会和"角色本来就在呼吸/摇摆"打架**，看起来像抖动；**按下缩放会和呼吸相位叠加**。所以：**悬停用光晕（不改变几何）· 按下用描边（不改变几何）· 点击用涟漪（一次性、会自己消失）**。
- **涟漪**：从点击点扩散、**不阻塞交互**、**必须能被"减少动效"关掉**。
- **验收**：① 悬停时**角色的几何尺寸不变**（断言，不是眼看）② 按下时尺寸不变、描边出现 ③ 涟漪结束后**无残留控件/无泄漏**（断言对象数回到基线）。

### A5【P1】贴边 300ms 缓动（用 `QVariantAnimation`，**目标位置计算不变**）

## 三、第 2 波 · 速胜（七条，**按你领到的分工做**）

- **B1** 拖拽时的光标（`ClosedHandCursor`/`OpenHandCursor`）+ **拖拽阈值**（小于阈值不进入拖拽态，避免误触）
- **B2** 气泡**淡入淡出**（时长走令牌表；**能被"减少动效"关掉**，关掉后瞬时）
- **B3** 气泡**跟随**角色（拖拽时气泡跟着走，不落在原地）
- **B4** 摸头**心形**（一次一串、会自己消失）
- **B5** hover tooltip（**只补"决定成败"的信息**，不铺满全仓按钮——上一版复盘过 tooltip 覆盖率 7% 而关键信息只在 tooltip 里）
- **B6** **错误可操作**（错误提示必须给"下一步能做什么"，不是只报错）
- **B7** **双击**走 `mouseDoubleClickEvent`（**不加 150ms 延迟**——用户明确否决过）
- **B8** 加载状态进度反馈（>1s 的操作要有进度或骨架）

**⚠ 每条都要先想清楚一件事并写进回报**：**它会不会让熟路多一步、会不会覆盖掉用户刚看的东西？**（这是上两轮最贵的教训。）
