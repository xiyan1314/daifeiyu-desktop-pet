## 一、D · 遗留-1（先做：最小、封闭、防"打包版守护不生效"）

现状（`REMAINING.md` §十四 遗留-1 的原文）：
- `大肥鱼桌宠.spec:5` 的入口是 `['桌宠.py']` → **打包 exe 上崩溃自动重启一次都不执行**；
- `启动桌宠.vbs` 靠 ASCII 标记 `daifeiyu_pet_main` **扫目录猜**主程序（现在只有 `桌宠.py:9` 有标记）；
- `pet_main.autostart_command` 的三条兜底路径都**写死** `桌宠.py`。

改法（三处同一条入口链）：
1. `main.py` 补同一枚标记 `# entry-marker: daifeiyu_pet_main`（老启动器仍能靠标记找到它）；
2. `启动桌宠.vbs`：**先显式试 `main.py`**（存在就用），再退回"扫标记"（兼容老包/改名）；
3. `pet_main.autostart_command`：新增纯函数 `entry_name(app_dir)`（存在 `main.py` 就返回它，否则 `桌宠.py`），
   三条返回路径全部改用它；
4. `大肥鱼桌宠.spec` 入口 → `['main.py']`。

**判据（都要能真失败）**：
- spec 的首个 Analysis 入口字符串 == `main.py`（改回 `桌宠.py` 必红）；
- `main.py` 含 entry-marker（删掉标记必红 —— 否则老 vbs 找不到入口）；
- `entry_name()` 三分支：两者都在→`main.py`；只有 `桌宠.py`→`桌宠.py`；都没有→`桌宠.py`（保守回退）；
- vbs 文本里 `main.py` 的显式分支出现在标记扫描**之前**（把顺序倒过来必红）；
- 回归：`pet_guard.decide` 的"正常退出不重启"原判据仍绿（不新写，跑既有的）。

## 二、C · D1 首次引导（一次性、可重入、落盘）

- 新配置键：`first_run_done`（默认 `False`，bool 归一化）；`tray_tip_done`（默认 `False`）——
  把今天那个**不落盘**的模块级 `_HIDE_TIP_SHOWN` 换成它（关窗提示只出现第一次）。
- 首次启动（`first_run_done` 为假）：弹 **一条**引导气泡（右键菜单 / 拖动 / 托盘三件事一句说完），
  随即写盘置真；**第二次启动不再弹**。气泡是"陪伴"不是"打扰"：不发声、不进系统通知。
- 写盘失败 → 仍然只弹这一次（不因落盘失败反复骚扰），并在 error.log 留痕。

**判据**：首启弹一次 + 标记落盘；同进程再调不弹；坏配置值（`"x"`/1/null/[]）归一成 bool；
落盘失败仍只弹一次且不抛。

## 三、C · E1 彩蛋（四类、低频、可关）

新模块 `pet_easter.py`（**纯逻辑、零 Qt、时钟与计数可注入**），四类触发：
1. **连戳**：窗口内被戳 N 次（默认 7 次 / 4s）；
2. **连喂**：窗口内被喂 N 次（默认 3 次 / 60s）；
3. **时段**：特定小时（默认 23 点后 / 5 点前 —— 与"时段问候"分开，不抢它的段）；
4. **角落**：桌宠停在屏幕角落半径内 >= T 秒（默认 8s）。

统一约束：**每类每天最多一次**（`easter_sent` 落盘，坏值回空表）；全局冷却 >= 30 分钟；
`easter_eggs` 默认 **开**（都是低频小惊喜），关掉即全部静默；**v1 不做屏幕震动**（只播台词/表情）。

**判据**：四类各一条触发；**同一天第二次不重复**；冷却期内不触发；关掉开关一条都不触发；
"时段"边界（22:59 不触发 / 23:00 触发）用注入时钟钉死。

## 四、C · D2 菜单悬停预览（默认关，不改状态）

- 新配置键 `menu_hover_preview`，**默认 `False`**；
- 动作子菜单里悬停 **300ms**（`pet_motion.DUR` 令牌，不散落字面量）→ 预览一次该动作；
- **预览模式 = 不落状态、不发声、不计入统计**：`play_action(..., preview=True)` 传下去，
  预览分支**不写 ledger / 不播 voice / 不改 cfg**，只播一次帧或表情；
- 移开 / 关闭菜单 → 取消在途计时器（一个动作都不许晚到）。

**判据**：300ms 前不预览、300ms 后预览一次；`ledger.json` 前后逐字节一致；
预览期间 `play_sound`/`voice.play_event` **零调用**（注入 spy）；默认关（不配就是关）。

## 五、A · root motion（主题）

- `pet_motion` 增 **root 步进令牌**（`ROOT = {"STEP_PX": 2}` 之类，产品码不许再出现字面量），
  `_walk_anim` 的解帧机制复用；
- **帧驱动**：走帧每推进一步，窗口按"朝向 × STEP_PX"位移（不是再来一套 tick 缓动）；
- **边界夹紧**：位移前按**当前屏可用区域**夹紧，角色**整只**不许出屏；被夹住时**停步不出屏**
  （不抖、不来回弹）；
- 无 walk 帧集（自定义角色 / 素材缺失）→ **老路照旧**（tick 缓动位移），一行都不改；
- 与"减少动效"的关系：root motion 是**位移**不是时长动画 → **不接**开关（A-07 的收窄口径 già 写死，
  新代码不许从这条缝里接进去）。

**判据**：① 走帧推进 → 位移 = 步数 × STEP_PX（方向随 flip）；② 右边缘处继续推进 → x 不超过可用区上限
（**整只不出屏**）；③ 无帧集 → 走帧路径零位移（老路仍然动）；④ root motion 不读 `_reduce_motion()`
（把它接上开关 → 必红）。
