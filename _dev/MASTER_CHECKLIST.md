## H · 六条铁律

1. 绿色版目录调 python 一律 `-B`；语法检查用 `ast.parse`（**别用 `py_compile`**）
2. 跑全量前确认 `_dev/.mutation.lock/` 不存在；**别人持锁时不跑不下结论**
3. **断言不许依赖机器速度**（注入固定成本 → 断言结构性事实）
4. **契约双向覆盖**；**不许放宽任何既有断言**
5. 定版前对着**出货修订**整批复跑全部证据；SPEC-BAD / ANCHOR-LOST / NOT CAUGHT / WRONG TEST **一律不许当通过**
6. **变异必须在影子副本里做**（原地改会制造 1~2 秒"真仓变异态"窗口，并发跑的人会看到假红）

**另两条口级铁律**：**口头追加 ≠ 文件落地**（必须写进任务书文件）· **"好像没做过"先查上轮是否已覆盖，再决定派不派**（不重复派活）。
