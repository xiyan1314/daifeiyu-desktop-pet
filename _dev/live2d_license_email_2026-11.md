## 正文（可直接粘贴）

您好，

我们是一个非商业、MIT 开源的 Windows 桌面宠物项目「大肥鱼桌宠」（PySide6 / Python）。项目免费分发、无营收、无内购，代码在 GitHub 公开。

我们计划在下一个版本加入 Live2D 渲染能力，方案是：
- 使用社区 Python 绑定 `live2d-py`（底层为 Cubism Core）；
- 只加载**用户自行导入**的 `.model3.json` 与贴图，**不随安装包分发任何模型文件**；
- 不做模型编辑器、不做动捕、不向用户提供“创建 Live2D 内容”的工具。

产品后续还会包含（非 Live2D 必需）：AI 对话、情境感知（时间/窗口状态，不含屏幕截图上传）、番茄钟等桌面助手功能。

想确认三点：

1. 在上述「MIT 开源、零营收、免费分发、用户自备模型」的前提下，使用 `live2d-py`（社区绑定，底层 Cubism Core）是否属于 Cubism SDK 的**免费许可**范围？是否需要签署 SDK 发行许可（出版许可协议）？
2. 产品包含 AI 对话/情境感知（**不含**动捕、**不含**用户创作工具）时，是否会被归入「可扩展性应用（拡張性のあるアプリケーション）」而需要另行审查/签约？若需要，个人开发者的流程、周期与费用大致是多少？
3. 我们不分发模型文件、只提供导入能力时，模型版权责任如何界定？是否还需要对“用户导入的模型”逐一取得许可？

如需要，我们可以提供仓库链接、功能说明与截图，配合贵司评估。期待书面答复，谢谢！
