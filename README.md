> 一只又娇又耍赖、贪吃、被吓到就浑身发抖的大肥鱼，会叫你「绳匠」~
> 名台词：**喜欢的，就咬住不放~**

[English](README.en.md)
透明无边框窗口、常驻置顶，可拖动、可投喂、可聊天、可查余额，陪你写代码摸鱼两不误。

## ✨ 特色

- 🖼️ **双形态帧动画**：常态 + 吃饱（圆鼓鼓）；待机 10 帧连续动画，喂食 7 帧吃播动画
- 😠 **戳戳情绪链**：戳一下→疑惑，2.5 秒内再戳→生气，再戳→哈气威胁
- 🍰 **喂食系统**：小鱼干 / 蛋糕 / 钻石三选一；点击→抛物线飞进嘴里，按住拖到身上也能喂
- 💬 **AI 对话**：接入 DeepSeek API，回复中文俏皮贱萌（≤25 字），带最近 3 轮短期记忆
- 💰 **余额挂件**（可选）：余额 + 今日已用实时显示，数字滚动动画，60 秒自动刷新
- 🔐 **密钥安全**：API Key 用 Windows DPAPI 加密存储，磁盘无明文；一键清除不留痕
- 🎵 **音效**：按压 / 松手 / 喂食 / AI 回复完成 / 余额到账音效（可开关）
- 🖐️ **摸摸头**：按住桌宠 1.5 秒 → petpet 摸头动画 + 害羞台词（借参考插件「petpet」概念）
- 💸 **撒钱动画**：查询余额成功 → 金币音 + 撒钱特效（借参考插件「money」概念）
- 😴 **小动作**：60 秒不理会就呼呼大睡；偶尔做坏事得意坏笑；被夸会害羞脸红
- 🐟 **称呼绳匠**：开场必定叫你「绳匠」，AI 回复也会这么叫
- 📌 单实例运行、系统托盘图标、跟随鼠标 / 散步、滚轮缩放、贴边吸附、开场大笑
- 🚀 **开机自启**（默认关闭，右键 →「⚙️ 设置…」自选）：写入注册表 Run 键，开机自动陪你上班
- 🐳 **v1.3 借鉴小鲸鱼插件（dsh-whale-widget）的整套自定义与记账能力**：
  - 🖼️ **角色导入**：右键 →「角色」导入素材（png/jpg/bmp/webp），自动去背景/裁剪/缩放；**1~8 个形态由你自定**（每个形态独立命名选图，如 幼体/成体/究极体），喂食依次切换形态、12 秒后回第一形态；可随时切换/删除/恢复默认；自定义角色自带**程序化表情图**（脸红腮红/愤怒筋/zzz 等叠加在素材上）
  - 🎞️ **多帧动画角色（v1.3.2）**：多选几张图片 = 帧序列；选一个**视频或 GIF 自动抽帧**（视频均匀采样 3~20 帧、GIF 3~24 帧）；每帧同样自动处理，待机时循环播放动画，喂食后切吃饱形态
  - 🔊 **音效导入 + 自定义音效组**：导入 wav/mp3 音频片段，试听/重命名/删除；5 个事件（戳一下/松开/喂食/AI 回复/金币）可各自指定片段或静音
  - 📦 **资源管理**：一个窗口统管角色与音频片段（预览/试听/设为当前/删除）
  - 📒 **记账功能**：余额差自动记账（跨天自动归档）+ 手动记一笔；账本窗口看今日/近 7 天/全部明细，支持搜索与导出 CSV；今日预算 / 余额预警到点弹提醒（每天一次）
  - 🎨 **气泡样式 + 自定义台词**：气泡底色/文字色/描边/字号/圆角随意调；撒娇/贪吃/开心/闲逛四类台词可自己加料
  - 🌈 **右键菜单美化**：深色圆角紧凑主题、大小滑块、emoji 图标、顶部余额/今日已用信息行
- 🐍 **啥子蛇性格**：对话性格参考绝区零希希芙（网友戏称「啥子蛇」）——自称只遵循本能的「坏蛋」、嘴上冷血毒舌实际心软，爱用「本专员」把贪吃耍赖包装成案件调查，偶尔「嘶~」吐蛇信子

## 🚀 快速开始

**方式一：免安装绿色版（推荐，无需 Python）**

到 [Releases](https://github.com/xiyan1314/daifeiyu-desktop-pet/releases) 下载附件 `daifeiyu-desktop-pet.zip`（解压后是 `大肥鱼桌宠_绿色版` 文件夹）→ 双击 `启动桌宠.vbs`。
（绿色版使用微软签名的 pythonw.exe + 完整运行库，不含易被杀软误报的自解压 exe。）

**方式二：源码运行**

```bash
pip install -r requirements.txt
python main.py        # 规范入口（桌宠.py 为兼容壳）；或双击 启动桌宠.bat
```

## 🎮 玩法

- 左键拖动移动（靠近屏幕边缘自动吸附），按住时有 Q 弹压扁效果
- 右键菜单（深色圆角紧凑主题，参考小鲸鱼挂件布局）：顶部余额/今日已用 + 🎚️ 大小滑块实时缩放；平铺开关（置顶/音效/AI 对话）；💭 和它说话 · 🍖 喂食（含食物托盘与形态）· 🐟 角色 · 💰 记账（余额挂件/账本/记一笔/预算/预警）· 📦 资源管理 · ⚙️ 设置…（跟随/散步/气泡样式/音效组/台词/API Key）；夸夸/天气/系统状态/关于/退出
- 打开食物托盘后不给它吃，8 秒会委屈到哭；看到食物会馋到流口水
- 吃饱形态约 12 秒后自动消化回常态
- 戳戳三连、夸夸脸红、CPU 超过 90% 自动冒泡提醒

## 🛠️ 平台与数据说明

- **仅支持 Windows**（winsound 音效、DPAPI 密钥加密、托盘均为 Windows 实现；暂不提供 macOS/Linux 版）
- 天气数据来自 [open-meteo](https://open-meteo.com/) 免费接口，默认城市为北京；右键 →「📍 天气城市…」可修改并保存
- 运行时数据全部保存在程序目录（只读目录自动回退 %APPDATA%\大肥鱼桌宠）

## 🧠 AI 对话与记账（可选）

1. 右键 →「设置DeepSeek API Key」填入你的 Key（sk- 开头，DPAPI 加密保存）；
   支持任意 OpenAI 兼容服务：右键 →「🤖 AI设置…」自填接口地址/模型名（内置
   DeepSeek/Kimi/豆包/通义/智谱/混元/星火/千帆/OpenAI/Groq/OpenRouter/MiniMax/
   硅基流动/本地 Ollama 一键填参考），「测试连接」当场验证，密钥无效/额度不足/
   地区限制/服务不可用等错误界面直接中文提示
2. 右键 →「和它说话」与它聊天；勾选「余额挂件」头顶常驻显示余额 + 今日已用
3. 右键 →「查询余额」：余额差自动记进账本（跨天自动归档）；「✏️ 记一笔」手动补记其他消费；「📒 账本」查看今日 / 近 7 天 / 全部明细并导出 CSV
4. 右键 →「💸 今日预算」「🚨 余额预警」设提醒阈值（0 = 关闭；每天最多提醒一次）
5. 分享前右键 →「清除DeepSeek API Key」一键擦掉 Key 与余额基准（手动记账保留）

> 所有网络请求走 HTTPS 并带超时；Key 加密绑定本机账户，拷到别的机器也无法解密。

## 🎨 自定义你的大肥鱼

- **换角色**：右键 →「🐟 角色」→「导入角色…」，素材**自动处理**（无透明底自动去背景、裁剪透明边距、超大图自动缩放，支持 png/jpg/bmp/webp）：
  - **多形态**：向导里可添加 1~8 个形态，每个形态自己起名、自己选图（不一定是「吃饱」，幼体/成体/究极体随你）；喂食依次切换，12 秒后自动回第一形态
  - **帧动画**：多选几张图片按文件名排序做帧序，或选视频/GIF 自动均匀抽帧（视频 3~20 帧、GIF 3~24 帧）；待机循环播放
  - 情绪 = 程序化表情图（腮红/愤怒筋/眼泪等直接叠加在你的素材上）+ 气泡 + 头顶表情；Q 弹压扁、贴边、跟随等程序效果全部保留
- **换音效**：右键 →「🎵 音效设置」→「管理音频片段…」导入 wav/mp3 并试听；「自定义音效组」里给每个事件单独指定片段（选「静音」= 该事件不出声）
- **换气泡**：右键 →「🎨 气泡样式…」调底色/文字色/描边/字号/圆角
- **加台词（v2.1 独立台词模块）**：右键 →「💬 自定义台词…」
  - 「台词库」页签：新建/编辑/删除/批量删除/搜索，**内置台词也能删**（可「撤销删除」或「恢复内置」找回），数量与长度不限；每条可指定**角色**与**声音**
  - 「对白编排」页签：把多条台词排成一段**多角色对白**，按顺序用各自声音依次朗读
  - 「失效引用」页签：台词引用的角色/声音被删后在这里明确列出（缺什么、为什么），可逐条修复/清空引用/删除，**不会自动删也不会静默替换**
- **换声音（v2.1 AI 配音）**：右键 →「🎤 语音设置…」
  - 「配音」页签选可插拔克隆后端（**GPT-SoVITS** 本地推荐 / F5-TTS / CosyVoice / MiniMax / ElevenLabs / OpenAI 兼容 / Windows 系统语音），点「测试后端」验证服务通不通
  - 「角色绑定」页签给每个角色（含默认角色）绑定一个声音素材；「朗读台词」页签选台词或对白 →「朗读 / 停止 / 重新生成」，相同声音+文本会命中缓存
  - 声音素材（参考音，建议 3~10 秒干净人声）在「🎵 音效设置 → 管理音频片段…」所在的**资源管理 → 声音素材**页签导入/试听/重命名/删除（与音效片段分开管理）
  - 打开「日常台词也用配音」，戳一戳/闲逛/摸头的随机台词也会用角色声音念出来
- **待机（v2.1）**：右键 →「😴 待机设置…」配两个触发（吃饱形态结束后延迟 / 无交互满 N 秒）、待机形态（留空=不切形态）、
  待机动作列表（可加多条行为，启停/权重/上下移）与播放模式（顺序轮流/随机/按权重/只播一条）；
  待机永远是最低优先级——说话、读台词、拖拽、喂食、手动切形态随时打断，待机绝不覆盖你选定的形态
- 所有自定义数据保存在程序目录（config.json、ledger.json / ledger_archive.json、roles/ + roles.json、audio/ + audio.json、lines.json、voice_assets.json + voice_ref/），换机器/升级时拷贝这些文件即可迁移

## 🛡️ 杀软误报说明

PyInstaller 打包的无签名 exe 会被杀软机器学习引擎误报（实测 Defender 报
`Wacapew.C!ml`），因此本项目**默认分发绿色版**（pythonw.exe + 源码），结构上
不存在被杀软误删的自解压 exe。若仍被拦截：加入信任 / 白名单，或直接用方式二源码运行。
全部源码公开可审阅，放心使用。

## 🔧 换成你自己的角色

**方式一（推荐，v1.3+）：** 右键 →「🐟 角色」→「导入角色…」选透明底 PNG 即可，支持多角色随时切换。

**方式二（替换默认形象）：**

1. 把角色图放到本目录，例如 `source.png`
2. `python 去背景.py source.png character.png`
3. 重新启动即可。常态/吃饱双形态图片按 `character.png` / `character_full.png` 命名
   （正面对应 `character_front.png` / `character_full_front.png`）
