## 二、V2EX（Python 节点）

**标题**：我用 Python 写了个会记账的桌宠，帮你盯着 DeepSeek 余额

**正文**：

```
用 Python + PySide6 写的 Windows 桌面宠物，从 1.0 迭代到现在 2.2.7，前后大概两个月。

最初只是想做个桌宠（喂食→吃饱变圆→消化变回来、多形态角色、待机打盹），
后来越加越多，现在比较有意思的几块：

1. AI 记账（独家）：读 DeepSeek 余额接口 + 本地账本，API 消费和手动记账分开记，
   支持今日预算与余额预警；桌面挂件直接显示余额，不用天天登后台。
2. 语音克隆：7 种 TTS 后端可插拔（GPT-SoVITS / F5-TTS / CosyVoice / MiniMax / ElevenLabs…），
   台词可以配自己的声音，启动器能一键拉起本地后端。
3. 台词库 + 对白：所有台词可增删改，支持分类（待机/开心/生气/喂食）、槽位绑定、多角色对白。
4. 行为系统：可视化编排动作序列（跳/表情/说话/等待/位移），配到待机上就是自定义待机动作。
5. 自定义角色：多形态角色（常态/吃饱/变身/睡觉），导出成 .dfypet.zip 分享给别人。

踩过的坑里最典型的一个：桌宠"吃完就待机、吃饱形态看不到"这个 bug，查了很久，
最后发现是代码里有两条互不相干的时钟——消化挂在"喂食那一刻"，待机动作挂在"程序启动那一刻"，
所以 zzz 出不出、出现在什么形态上，完全取决于你什么时候喂。改成事件时钟才对。

绿色版免安装（自带 python + 运行库，解压双击就行），也可以源码跑。
MIT 协议，欢迎来玩：https://github.com/xiyan1314/daifeiyu-desktop-pet
```

## 三、掘金（技术向，加实现细节）

**标题**：我用 Python 写了个会记账的桌宠，帮你盯着 DeepSeek 余额

**结构建议**：

1. **为什么做**：桌宠 + 一个真实的痒点（DeepSeek 按量计费，想随时看到余额和今日用量）
2. **技术栈**：Python 3.10 + PySide6 6.11（Qt6）/ 绿色版打包 / 25 个模块约 2.2 万行
3. **三个值得写的实现**：
   - **透明无边框窗口 + 桌面物理**：甩抛、弹簧回弹、多屏/混合 DPI 落位
   - **状态机**：形态归属（用户选定形态 vs 临时展示：待机/睡眠/变身/吃饱），谁都不能吞掉谁；
     配 674 行"状态不变量"测试（单动作/两连/三连/收尾回调 全组合）
   - **两条时钟的教训**：消化挂事件时钟、节拍挂绝对时钟 → zzz 随机错位；
     改成全事件时钟后，用"相位无关"验收（喂食 0.5s/5s/16s 三相位 × 7 项断言）
4. **护栏体系**：pytest 263 例 + 静态体检（tokenize 级去注释、QTimer 生命周期、空池 AST 判定）
   + 267 项端到端验证 + 绿色版成品检测 + 发布检测（版本三处一致/包干净/逐字节比对）
5. **AI 记账怎么做的**：DeepSeek 余额接口轮询 + 本地账本（API 消费与手动记账分账）+ 预算预警
